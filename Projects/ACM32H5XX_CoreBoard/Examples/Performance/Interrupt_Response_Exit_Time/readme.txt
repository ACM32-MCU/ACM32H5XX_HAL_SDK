ITCM使能后，0地址开始的32KB被映射到ITCM；DTCM使能后，0x20000000地址开始的32KB被映射到DTCM。使能后，ITCM/DTCM就能像SRAM一样访问了。在使能之前，不得访问TCM地址空间。
本Demo中reset_handler首先使能DTCM，然后在SystemInit函数会使能ITCM，并关闭全局中断，该接口需要在__main函数之前被调用。
本Demo中，将0x08002000开始的中断向量表拷贝到0地址开始的地方，并将中断向量表映射到0地址然后使能全局中断，将中断入口函数链接到DTCM，这样的配置，中断响应和中断返回的时钟周期数最少，
分别为20和19个HCLK左右。
本Demo使用SVC指令来产生SVC中断的方式来测试中断响应时间。
